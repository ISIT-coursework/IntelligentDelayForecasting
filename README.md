# Интеллектуальная система прогнозирования задержек грузовых перевозок и информационной поддержки логистических решений

Цель проекта:
Разработка системы для прогнозирования задержек грузовых рейсов с помощью ML и поддержки принятия решений диспетчерами на основе RAG-системы, использующей регламенты заказчика.
